## ✨ 为什么用这个升级版？

写小说最难的是**坚持写完**以及**把控语言风格特质**。这个升级版 Skill 专为解决这些痛点而生：

- **多语种与文风定制** - 可提供英文等外文范本，智能提取词汇量与句式要求，彻底摆脱千篇一律的AI生成腔调，精准还本文风。
- **无脑创作** - 阶梯式回答 7 个问题，剩下的交给 AI。
- **灵活的输出切分** - 可选是一口气写完，还是只写到指定章节或指定特定情节（AI自动拆分算章）。
- **确认才开动** - 完整规划好大纲、拆分了段落并得出词汇分析结果后强制要求你确认才开始正文。
- **Notes-first 连贯写作** - 写作阶段默认优先读取规划文件和前文 notes，不反复回读原文，节省上下文并保持连贯。
- **终稿总审查** - 全部章节完成后通读 chapter 原文，统一回填大纲、人物、时间线、全局备注和各章 notes。

### 四段式创作流程

**第一阶段：7 问逐一确认**

AI 会逐一向你展示菜单并询问需求：

```
📝 问题 1/7：使用什么语言创作？（若附参考文章，AI会记录词汇量和句式语法级别，严格遵从生词限制）
   □ 中文
   □ 英文（默认）
   □ 英文（附上参考文章内容...）
   □ 其他语言
   
📝 问题 2/7至6/7：确定题材、人物、性格、核心冲突、计划总章数
   ...
   
📝 问题 7/7：希望本次自动写作的范围是？
   □ 一次性自动写完全文
   □ 强制只写到指定章节（如写到第5章结束）
   □ 强制写到指定情节（如写到某个主角找到钥匙的关键剧情点）
```

*如果你选择了"指定情节"，AI会在后台在随后的规划阶段为你自动定位该情节所处的精准章节，并设置为停止点！*

**第二阶段：规划展示 + 二次确认**

AI 自动生成规划文件、设定好终止范围，展示给你确认。规划阶段会先完整落地这 4 个核心文件：

- `00-outline.md`
- `01-characters.md`
- `02-timeline.md`
- `03-global-notes.md`

然后再展示摘要供你确认：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
规划完成！请确认以下内容：

基本信息
  题材：悬疑推理（英文写作）
  语言词汇级别：基于用户给定的文本限制在 CEFR B1 中等长句水平
  主角：侦探主角
  核心冲突：查明真相
  计划总章节：20章
  本次生成上限：写到第3章（满足触发发现凶杀案情节条件）

章节规划
  第1章：午夜凶铃 - 主角接到神秘电话
  第2章：第一具尸体 - 发现密室杀人案
  ...

主要角色
  主角：李明 - 资深刑警，冷静智慧
  反派：张华 - 高智商罪犯

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

回复"确认"或"开始" → 立即进入疯狂创作模式
提出修改意见 → 调整后重新确认
```

**第三阶段：notes-first 写作循环**

确认后，AI 进入循环写作模式，并严格遵守这个顺序：

1. 先读取规划文件和前文 `chapter-notes`
2. 先写一个 `chapter`
3. 再写这个 `chapter` 对应的 `chapter-notes`
4. 再进入下一章

后续写作时，默认不回读前文 chapter 原文，只读对应 notes；如果上下文过大或临近超时，就只靠规划文件和前文 notes 继续写。

**第四阶段：终稿审查与回填**

全部 chapter 完成后，AI 会进入最后一轮审查：

1. 通读 `chapter` 原文，而不是只看 notes
2. 核对时间线、剧情、人设和伏笔是否冲突
3. 根据最终定稿的 chapter 内容，统一优化 `00-outline.md`、`01-characters.md`、`02-timeline.md`、`03-global-notes.md` 和各章 notes
4. 一旦发现冲突，立即修改正文和相关规划文件

## 🎯 核心法则

| 法则 | 说明 |
|-----|------|
| **展示而非讲述** | 用动作和对话表现，不要直接陈述 |
| **冲突驱动剧情** | 每章必须有冲突或转折 |
| **精准控制范围与词汇** | 完美执行中止范围计划，并严格满足用户外语词汇量量级或句型特征 |
